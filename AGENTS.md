This project is a mattpocock claude plugin convertor to antigravity plugin.

It can clone https://github.com/mattpocock/skills the repo and use the claude plugin which is already to produce agy plugin.


Use mise-en-place for defining required tools.
Use mise tasks if the tools doesnt have a launcher or use it for convinience tasks which are run often.

# Verification
Use one of his skills to check the availbility. For example `agy --print "/wayfinder"` should not print error.
